제가 추구하는 것은 특정 기술 자체가 아니라 실제 문제를 해결하고, 만든 결과가 제대로 작동하는지 확인할 수 있는 일입니다.

개발, 보안, 데이터, 아키텍처, AI는 그 목적을 위한 수단으로 봅니다. 특히 AI는 목적이 아니라 기존보다 더 넓은 문제를 해결하기 위해 현재 적극적으로 활용하는 도구입니다.

문제 이해 → 적절한 수단 선택 → 실제 구현 → 결과 검증

기술·업무 기록은 아래 목록에서 주제별로 확인할 수 있습니다. 주택, 생활계획처럼 기술 블로그의 본문 흐름과 다른 개인 기록은 Notes에 별도로 정리합니다.

먼저 볼 글

  • AI는 목적이 아니라 문제 해결을 위한 수단이다
  • ChatGPT를 활용해 GitHub Pages 기술 블로그를 시작합니다
  • Rocky Linux 디스크 마운트 실패 대응 절차
  • Apache VirtualHost 404 장애 원인 분석
  • 분석 결과를 웹 서비스로 시스템화할 때 고려할 점
