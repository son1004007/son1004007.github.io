최근에는 ChatGPT와 Codex를 단순한 질문 도구가 아니라 문제 정의 → 계획 → 구현 → 테스트 → 문서화를 함께 수행하는 작업 도구로 활용하고 있습니다. 대화에서 끝난 내용을 GitHub에 남겨 다음 작업과 다른 AI 세션에서도 다시 사용할 수 있게 만드는 것이 이 블로그의 중요한 주제 중 하나입니다.

대화 → 문제 정의 → 계획 → 구현 → 테스트 / 검증 → GitHub 기록 → 다음 작업

기술·업무 기록은 아래 목록에서 주제별로 확인할 수 있습니다. 주택, 생활계획처럼 기술 블로그의 본문 흐름과 다른 개인 기록은 Notes에 별도로 정리합니다.
